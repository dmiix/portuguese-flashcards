# Portuguese Flashcards

European Portuguese flashcards with pt-PT audio (Microsoft Raquel voice), served with GitHub Pages.

- `<deck>/index.html`: desktop version (keyboard shortcuts)
- `<deck>/mobile.html`: touch version for iPhone and iPad (tap to flip, swipe to move)
- `sync.js`: optional "Know it" sync through a private gist on the viewer's own GitHub account (the token stays in the browser)

Rebuild after adding a deck to `decks.json`: `python3 -I _build/build.py`
